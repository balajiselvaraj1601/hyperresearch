# Phase A4: Ship gate

Template: `../PHASE-TEMPLATE.md`. Owner: watcher. The worker may have looked at the report. The watcher trusts the manifest.

**Purpose.** Answers: does the vault itself accept this report?
**Runs in:** the watcher tick, after the worker prints `DONE <slug>` or the session ends.
**Starts from:** B16 gate Pass or Conditional pass.
**Ends with:** manifest status `done` and `verify.passed` true, or status `blocked` with `blocked_on` `verify`.

#### E. Entry criteria

| # | Criterion | Mandatory or advisory | Check | Evidence |
|---|---|---|---|---|
| E1 | B16 gate is Pass or Conditional pass | mandatory | last B16 line in gates.jsonl | gates.jsonl |
| E2 | Manifest exists | mandatory | `output/runs/<tag>/run.json` | run.json |

#### W. Work steps

1. If status is not done, run `uv run hyperresearch run finish <vault_tag> -j` from `apps/hyperresearch`.
   - Produces: `verify` on the manifest.
   - In-step quality check: do not reinterpret a failing check.
2. On failure, a resumed worker may edit the report. At most three rounds. Then A4 again.
   - Produces: a new gate line per round.
   - In-step quality check: round 3 still failing leaves the row blocked.

Allowed fixes: length over the ceiling gets one compression pass and no new critic round; quote-integrity loses rhetorical quotation marks or becomes verbatim; retracted citations are acknowledged or removed; critical-findings-resolved re-enters B14; anything else edits only the artifact the check names.

#### X. Exit criteria

| # | Criterion | Mandatory or advisory | Result | Evidence |
|---|---|---|---|---|
| X1 | status is done and verify.passed is true | mandatory | | run.json |
| X2 | The report file exists | mandatory | | output/reports/<tag>/final_report_<tag>.md |

`gate_check.py` with `PHASE=A4` only reads. It does not call `run finish`.

#### A. Abort

- A failed finish sets the row blocked and writes the failing check names into `error`.
- Re-entry is a resumed worker, then A4 again. A5 does not copy a blocked report.

#### H. Handoff

- Next phase is A5, owned by the watcher: copy the report, checksum, then mark the row done.
- `permission` on a Pass line is `Phase A5 may start`.
