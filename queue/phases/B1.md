# Phase B1: Decompose

Template: `../PHASE-TEMPLATE.md`. Procedure: `uv run hyperresearch run contract <vault_tag> 1` from `apps/hyperresearch`. Never the raw skill file.

**Purpose.** Answers: What exactly was asked, item by item?
**Owner:** muse-worker
**Runs in:** one Muse exec or one OpenCode run for this phase, inside tmux `orch-hyperresearch-<slug>`.
**Starts from:** the previous phase gate, Pass or Conditional pass.
**Ends with:** a gate line in `dump/apps/hyperresearch/<slug>/output/runs/<vault_tag>/.work/gates.jsonl`.
**Tiers:** light and full
**Roles:** No role spawn. The worker uses the CLI only.

#### W. Work steps (numbered, each names what it produces)

1. Render the step 1 contract and write the decomposition, coverage matrix, and tier.
   - Produces: prompt-decomposition.json, temp/coverage-matrix.md
   - In-step quality check: JSON parses and Gap? = YES is absent
2. Run levers render.
   - Produces: shims/research.md, drafting.md, critics.md, polish.md
   - In-step quality check: all four files non-empty
3. Record the tier rationale on the scaffold. If it disagrees with the registry tier, stop for Replan.
   - Produces: scaffold.md tier rationale
   - In-step quality check: gate_check.py exit 3 on disagreement

The work steps above are the order. The words of the procedure are the rendered contract. Every role spawn ends with `uv run hyperresearch run contract <vault_tag> --role <role>` pasted verbatim, after the shim the contract names. Cite-checker gets no shim. Absolute paths only. Fetch with `uv run hyperresearch fetch`, never WebFetch.

#### A. Abort, escalation, re-entry

- Abort trigger: decomposition still missing after one retry. Hold. Owner: muse-worker. Escalation destination: the registry `error` column and status `blocked`.
- Re-entry after Hold: fix this phase, run `gate_check.py` again, append a new gate line. Do not edit the old line.
- Database locked: sleep and retry at most twice. Do not delete the database, the WAL, or lock files.
- Do not write a stub artifact to make this gate pass.

#### H. Handoff

- State transition: `uv run hyperresearch run step <tag> 1 --status done -j` only after exit 0 or 2.
- Status line appended to `dump/apps/hyperresearch/<slug>/output/runs/<vault_tag>/.work/status.log`.
- Next phase is B2. Its entry is this phase's accepted gate.
- Long results cross phases as file paths.
