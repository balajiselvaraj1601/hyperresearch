# Phase B14.5: Cite check

Template: `../PHASE-TEMPLATE.md`. Procedure: `uv run hyperresearch run contract <vault_tag> 14.5` from `apps/hyperresearch`. Never the raw skill file.

Light tier does not run this phase. `gate_check.py` returns Pass with `skipped: true` and does not require these files.

**Purpose.** Answers: Does each citation support its sentence?
**Owner:** muse-worker
**Runs in:** one Muse exec or one OpenCode run for this phase, inside tmux `orch-hyperresearch-<slug>`.
**Starts from:** the previous phase gate, Pass or Conditional pass.
**Ends with:** a gate line in `dump/apps/hyperresearch/<slug>/output/runs/<vault_tag>/.work/gates.jsonl`.
**Tiers:** full
**Roles:** `cite-checker` with no shim, then `patcher` only for cite findings.

#### W. Work steps (numbered, each names what it produces)

1. Run citecheck extraction, spawn the cite-checker, patch criticals.
   - Produces: cite-check-pairs.json, cite-check-findings.json, cite-check-patch-log.json
   - In-step quality check: every critical is applied or escalated
2. Record step 14.5 done. run resume will not remind you. profile_steps omits 14.5.
   - Produces: run.json steps.14.5
   - In-step quality check: status done

The work steps above are the order. The words of the procedure are the rendered contract. Every role spawn ends with `uv run hyperresearch run contract <vault_tag> --role <role>` pasted verbatim, after the shim the contract names. Cite-checker gets no shim. Absolute paths only. Fetch with `uv run hyperresearch fetch`, never WebFetch.

#### A. Abort, escalation, re-entry

- Abort trigger: resume says the next step is 15. Ignore that and run this phase anyway. Hold if the step status is not done, because run verify then skips cite-check-resolved. Owner: muse-worker. Escalation destination: the registry `error` column and status `blocked`.
- Re-entry after Hold: fix this phase, run `gate_check.py` again, append a new gate line. Do not edit the old line.
- Database locked: sleep and retry at most twice. Do not delete the database, the WAL, or lock files.
- Do not write a stub artifact to make this gate pass.

#### H. Handoff

- State transition: `uv run hyperresearch run step <tag> 14.5 --status done -j` only after exit 0 or 2.
- Status line appended to `dump/apps/hyperresearch/<slug>/output/runs/<vault_tag>/.work/status.log`.
- Next phase is B15. Its entry is this phase's accepted gate.
- Long results cross phases as file paths.
