**Purpose.** Answers: Where do the positions conflict?
**Owner:** muse-worker
**Runs in:** one Muse exec or one OpenCode run for this phase, inside tmux `orch-hyperresearch-<slug>`.

#### A. Abort, escalation, re-entry

- Abort trigger: file missing or heading-only. Hold. Owner: muse-worker. Escalation destination: the registry `error` column and status `blocked`.
- Re-entry after Hold: fix this phase, run `gate_check.py` again, append a new gate line. Do not edit the old line.
- Database locked: sleep and retry at most twice. Do not delete the database, the WAL, or lock files.
- Do not write a stub artifact to make this gate pass.

- State transition: `uv run hyperresearch run step <tag> 6 --status done -j` only after exit 0 or 2.
